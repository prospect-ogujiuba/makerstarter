# MakerStarter

A WordPress 6.8+ full-site-editing theme and neutral professional design system. PHP 8.2+ is required.

The base templates use only WordPress core blocks, so the site remains usable without MakerBlocks. Patterns in `patterns/` may offer optional MakerBlocks compositions.

## Structure

- `theme.json`: colors, fluid typography, spacing, layout, and radii.
- `templates/`: page and archive templates.
- `parts/`: header and footer.
- `patterns/`: core-only and MakerBlocks compositions.
- `styles/`: global style variations.

Run `npm test` before packaging or publishing.
